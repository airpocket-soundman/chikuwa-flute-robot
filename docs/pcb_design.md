# やまびこ1号 基板設計メモ

作るのは **2 枚**。どちらも外部デバイスとは XH コネクタでつなぐ。

| 枚 | 名前 | 載せ先 | 役割 |
|---|---|---|---|
| A | **ドライバーシールド** | Arduino UNO Q の R3 ヘッダー（D0–D13 / A0–A5 / 電源） | アクチュエーターの駆動と、3.3V 系センサー・ボタンの引き出し |
| B | **オーディオ子基板** | UNO Breakout Carrier（ASX00085）の J14 / J15 | I2S マイクと、I2C・アナログ系の引き出し |

拡張ボードは **UNO Breakout Carrier（ASX00085 / スイッチサイエンス 11136）**。
`docs/idea.md` が前提にしていた UNO Media Carrier とは別物なので、
「Media Carrier のマイク端子 → Linux」という保険経路は、B 基板の `MIC2_IN±` に置き換わる。

データシート: [`datasheets/ASX00085-uno-breakout-carrier-datasheet.pdf`](datasheets/ASX00085-uno-breakout-carrier-datasheet.pdf)（2026-09-15 版）

## 先例: IchiPing-UNO-Q

<https://github.com/airpocket-soundman/IchiPing-UNO-Q> に、**同じ構成の 2 枚（UNO Q shield + Audio shield）が
すでに製造・実装・動作**している。回路・コネクタ・部品の選定はここに揃えるのが安全。

| 学べること | 中身 |
|---|---|
| **I2S マイクは動く** | INMP441 を **MI2S0（SoC 側、1.8V）**で動かした実績。`docs/uno_q/hardware.md` |
| B 基板の形 | J14/J15 に 2×20 メスソケット（秋月 100085）を 2 個。まさに今回の B 基板と同じ |
| A 基板の形 | UNO ヘッダーへ 1×8 ×2 / 1×10 / 1×6 のメスソケット（秋月 110299 を切って使う） |
| XH の型番 | 1×02 秋月 112247 / 1×03 112248 / 1×04 112249 / 1×05 112250 / 1×06 112251。**フットプリントは 2.54mm 穴で承認済み** |
| 0Ω よりジャンパ | 設定用の 0Ω 抵抗は 2.54mm ジャンパピン + ショートピンへ置換済み（`REPAIR_STATUS.md`） |
| **落とし穴** | **J14/J15 の奇数列・偶数列の向きを間違えて直している**（上面視で奇数列を左、偶数列を右）。嵌合面で左右が反転するので、公式資料と照合すること |
| 検査の作法 | 部品パッドとドリルデータの全数照合（`DRILL_CHECK.md`）、回路図とPCBのネットリスト差分 0 件の確認。DRC 0 件だけを製造可の判定にしない |

### MI2S0 の配線（IchiPing-UNO-Q 実績値）

QRB2210 の primary MI2S は 48kHz、ステレオ、32bit スロット（有効 24bit）。BCLK は 3.072MHz。

| 信号 | SoC GPIO | Breakout Carrier | INMP441 |
|---|---:|---|---|
| BCLK / SCK | 98 | J15-32 | SCK |
| WS / LRC | 99 | J15-34 | WS |
| DATA0（録音） | 100 | J15-36 | SD |
| DATA1（再生） | 101 | J15-38 | —（アンプ側） |
| 電源 | — | J14-19 / 21 | **VDD = 1.8V** |
| L/R | — | GND | L/R = GND |

安全則（先例からそのまま持ち込む）:

- **MI2S0 は 1.8V。3.3V / 5V の信号を絶対に繋がない。**
- マイクは信号線より先に電源を入れる。配線変更は電源を切ってから。

### 電源

- 入力 → 12V（ファン・電磁弁）
- 12V → 6V DC/DC（SCS0009）
- 3.3V は UNO Q のヘッダーから取る（センサーのロジックのみ。**5V は使わない**）
- アクチュエーターが 24V 品なら 24V 入力 → 12V 降圧が要る（未確定事項 1）

## B 基板: オーディオ子基板

### 機械（ASX00085 データシート 5 章）

- キャリア基板 107.6 × 53.34mm、取付穴 Ø3.2、穴間 101.61 × 47.34mm
- J14 / J15 は **2×20、2.54mm ピッチのオスヘッダー**、全長 50.8mm（= 20 × 2.54）
- **J14 と J15 の中心間 15.24mm（= 6 × 2.54）**
- ヘッダー高さ 9.5mm、基板厚 1.58mm

→ 子基板は 2×20 メスヘッダー 2 個を 15.24mm 間隔。2.54mm グリッドに素直に乗る。

### 使うピン（データシート 3.2.1 / 3.2.2）

| 用途 | ピン | 信号 | レベル |
|---|---|---|---|
| I2S マイク（本命） | J15-32 / 34 / 36 | `SOC_GPIO_98 / 99 / 100` | **1.8V** |
| （将来）I2S 再生 | J15-38 | `SOC_GPIO_101` | 1.8V |
| I2C | J15-16 / 18 | `MCU_I2C4_SCL / PF14`、`MCU_I2C4_SDA / PF15` | 3.3V |
| アナログ前段 | J15-20 / 22 / 24 | `OPAMP1_VOUT / PA3`、`VINP / PA0`、`VINM / PA1` | 3.3V |
| アナログマイク（保険） | J14-20 / 22 / 24 | `MIC2_INP` / `MIC2_INM` / `MIC2_BIAS` | — |
| マイク電源 | J14-19 / 21 | +1V8 | |
| ロジック電源 | J14-13 / 15 | +3V3 | |
| | J14-7 / 9 | +5V USB | |
| | J14-1 / 3 | VIN（7–24V 入力） | |
| GND | J14-5,6,11,12,17,18,23,25,26,31,32,33,37 / J15-23,30,40 | | |

**J15 には GND 以外の電源ピンがない。** 1.8V も 3.3V も必ず J14 から取る。

### 3.3V の MCU SAI1 は使わない

`idea.md:142` は MCU の SAI1（PE4/PE5/PE6 = J15-9/8/10、3.3V）を本命としていたが、

- 同資料自身が「UNO Q の MCU で I2S マイクを動かした公開の成功例はまだ見当たらない」と書いている
- 一方、**1.8V の MI2S0 は IchiPing-UNO-Q で実際に動いている**

ので、**MI2S0 を本命**にする。PE4/PE5/PE6 はテストパッドに引き出すだけにして、実装はしない。
`idea.md:138` が主張する「5〜15ms の低遅延フィードバック」は MCU 経路の前提だったので、
**MI2S0 → Linux の実測遅延を測って、やまびこの制御が成立するかを確かめる**のが最初の検証項目になる
（先例のリポジトリにも I2S 取り込みの遅延の実測値はない）。

### コネクタ（XH）

| リファレンス | 極数 | 中身 | 秋月 |
|---|---:|---|---|
| J_MIC | 6 | 3V3 / GND / SCK / WS / SD / L-R（先例と同じ 6 極） | 112251 |
| J_MIC_ANA | 3 | `MIC2_INP` / `MIC2_INM` / `MIC2_BIAS`（保険経路） | 112248 |
| J_I2C4 | 4 | 3V3 / GND / SDA / SCL | 112249 |
| J_AIN | 3 | OPAMP 入力（アナログ差圧センサー用） | 112248 |
| JP_LR | 2 | マイクの L/R 設定ジャンパ（先例に倣いショートピン） | — |

I2S ケーブルは BCLK 3.072MHz が乗る。**20cm 以内**に抑え、SCK / WS / SD に 33Ω の直列抵抗を入れ、
コネクタ内で GND を隣接させる。

## 未確定事項

1. **電源電圧。** アクチュエーターが 24V（`idea.md:41`）、ファンが 12V（`yamabiko.md:74`）で食い違っている。
   24V 単一入力 → 12V/6V 降圧か、12V 入力でアクチュエーターを 12V 品にするか。
2. **アクチュエーターのストール電流。** H ブリッジの型番（DRV8876 / TB67H450 / BTS7960 …）と XH の線径が決まらない。
3. **D0/D1 の衝突。** `mcu/uno_q_hil/uno_q_hil.ino:27` の HIL が Serial1 を使う。本番は Bridge 経由で D0/D1 を空けられるか。
4. **UNO Q 側の D ピン ↔ STM32U585 の対応と PWM/タイマーの割り当て。** A 基板の表は Uno R3 の慣習からの推定。
   UNO Q のデータシートで裏を取る。
5. **J14/J15 の奇数列・偶数列の向き。** 先例が一度間違えた箇所。公式資料の上面図と嵌合面で必ず照合する。

# step3 — 耳も NN（2026-11-23、録音とシミュレーターで評価、実機でも評価）

step2 の音程の推定（YIN）を、実機の録音で学習した耳の NN に替えた版。アクチュエータ・タンギング・耳がすべて NN。
[models/step3/](../models/step3/) にあり、step1・step2 と並べて置いてある。

## 中身

| 部分 | step3 での担い手 |
|---|---|
| 耳（マイクの 20 ms → 音程） | **NN**（`ear_01`、`flute_rl/yamabiko/ear_nn.py`）。3 層の 1 次元 CNN、25 cent 刻み 96 区分＋鳴っているか |
| DC リニアアクチュエータの PWM | NN（step2 と同じ） |
| 切換え弁（タンギング） | NN（step2 と同じ） |
| 演奏前の戻し・キャリブレーション | 規則 |

口笛の解析（ウェブ画面の口笛コピー）は YIN のまま（口笛は 1〜4 kHz で、耳の NN の範囲 310〜1250 Hz の外）。

## 耳の NN の作り方

```bash
python scripts/yamabiko_ear_data.py                       # 実機の録音 28 分 → runs/ear/dataset.npz
python scripts/yamabiko_ear_train.py --out runs/ear/ear_01  # GPU で十数秒
```

- 入力：実機で耳が聞くのと同じ、その場の 20 ms（320 サンプル）
- 正解：後から時間をかけて求めた音程（中心 64 ms の窓、250 Hz 未満を除き、YIN と FFT のピークが一致したものだけ、前後の中央値）。一致しないフレームは音程の学習に使わない
- 増強：音量、白色雑音、50〜110 Hz の唸り（ファンの真似）
- 録音は 5 本に 1 本を評価用に分けた

## 成績（学習に使っていない実機の録音）

| | 耳の NN | YIN |
|---|---|---|
| 鳴っている音の ±25 cent 以内 | 96.6 % | 96.7 % |
| 誤差の中央値 | **1.9 cent** | 3.9 cent |
| 聞き逃し | **0.03 %** | 2.5 % |
| モーター音の中で役に立った割合 | **73 %** | 41 % |
| 処理時間（PC） | 0.1 ms | |

モーター音の中の評価は、前後の正解から推し量れる短い区間（506 フレーム）で、±50 cent 以内に当たった割合。

## 実機での評価（2026-11-23、ハード設定を変えた後に step1・2・3 を同じ日に続けて評価）

`python scripts/yamabiko_step_eval.py --steps step1 step2 step3 --targets f80_doremi f80_scale f80_chromatic --repeats 2`
（各 step でキャリブレーションし直し、ホーム音はどれも約 429 Hz。結果は `runs/real/eval/20261123_174554_*`）。2 回の平均：

| step | 曲 | 音程の誤差（cent） | 音の間隔の誤差（cent） | ±25 cent 以内 | 滑る音 | 鳴った割合 |
|---|---|---|---|---|---|---|
| step1 | ドレミファミレド | 37.9 | 22.4 | 55 % | 29 % | 99 % |
| step2 | ドレミファミレド | **24.0** | **12.1** | **67 %** | **18 %** | 98 % |
| step3 | ドレミファミレド | 26.2 | 16.5 | 63 % | 20 % | 99 % |
| step1 | 音階 | 74.3 | 121.3 | 41 % | 34 % | 88 % |
| step2 | 音階 | 61.1 | 16.3 | 56 % | 25 % | 75 % |
| step3 | 音階 | **30.4** | **13.3** | **58 %** | **23 %** | **96 %** |
| step1 | 半音階 | 61.6 | 38.9 | 41 % | 37 % | 90 % |
| step2 | 半音階 | 47.4 | 56.7 | 54 % | **15 %** | 87 % |
| step3 | 半音階 | **28.4** | **10.4** | **55 %** | 16 % | **94 %** |

- step2 はアクチュエータとタンギングの NN の学び直しで、ドレミファミレドが大きく良くなった（音程の誤差 38 → 24 cent、滑る音 29 → 18 %）。
- step2 の音階・半音階は、上の音域（1000〜1200 cent）で YIN が音程を取れずに途切れ、音程が見えないアクチュエータが大きく振れた（鳴った割合 75 %）。
- step3 は耳の NN が最高音まで音程を追い、音階で 61 → 30 cent、半音階で 47 → 28 cent。3 曲とも音程の誤差が 26〜30 cent にそろった。
- 駆動信号の向きの反転は step1 の 11〜36 回に対し step2・3 は 27〜41 回（滑らかさは少し落ちた）。

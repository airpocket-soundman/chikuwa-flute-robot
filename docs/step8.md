## 中身

| 部分 | 何をするか | 由来 |
|---|---|---|
| 耳 | 毎フレーム、音程とその内部の符号を出す | step5 の `ear_06` |
| 記憶 | 聞く間は耳の符号を `W` に書き込み、吹く間は `W` から楽譜を読み出す | step6 の記憶（`mem_06`、下の追記） |
| 演奏・弁 | 思い出した楽譜の先読み、聞こえた音程、前の指令から PWM と息 | step7c（新しいツインで学び直した版） |
| **指揮役（新）** | ボタン・「終わった」・直前の状態 → 待機／聞く／吹く と、ファンの強さ | 小さな MLP（5→16→4） |
| **終わりの判定（新）** | 再生位置の前後で、記憶に書き込まれた量と「鳴っていたか」→「曲が終わった」 | 小さな MLP（22→32→1） |

- **楽譜の配列がない**：演奏 NN の先読み（10 か所）は、要るときに記憶から読み、一度読んだ値は覚えておく（`Recalled`）。
  step6・7 は、聞き終えたあとに楽譜を配列にしてから吹いていた。
- **終わり**：記憶の最後の行（書き込みの量）は、聞いた範囲ではほぼ一定で、その先では 0 に近い。これと「鳴っていたか」で、最後の音から 0.6 秒たったら「終わった」を出す。
- **まだ規則のまま**（計画どおり、まず外に残す）：ファンが回り始めるまでの 3 秒（弁は閉）、演奏前の原点出し 1.3 秒、最初の音の前の 0.6 秒、較正で測ったずれの足し込み。安全の上限はサーバーとファームウェアに残す。

## 成績（シミュレーター、1 話を丸ごと）

`scripts/yamabiko_step8_sim.py`：待機 0.5 秒 → ボタン → 口笛を聞く → ボタン → ファンと原点出し → 演奏 → 自分で止まる。
吹いている間の音程はシミュレーターが渡す（耳は口笛だけを聞く。`yamabiko_compare_sim.py` と同じ）。
比べる相手は、同じ口笛から規則で作った楽譜（いまの step7c が吹く楽譜）。

| ±25 cent 以内（4 台） | step8 | 記憶を配列で思い出して step7c で吹く | 規則の楽譜を step7c で吹く |
|---|---|---|---|
| 合成の口笛 8 曲 | 31 %（調を除くと 47 %） | 31 %（48 %） | 61 %（61 %） |
| 実機の口笛（学習に使っていない 2 本から 8 か所） | 35 %（39 %） | 36 %（48 %） | 67 %（76 %） |

| 止まる時刻（楽譜の終わり＝最後の音から 0.6 秒との差） | |
|---|---|
| 合成の口笛 32 話 | 平均 +0.01 秒 |
| 実機の口笛 32 話 | 8 か所中 6 か所は 0.2 秒以内、2 か所は 0.6 秒早い、1 か所は 5.6 秒早い（ほとんど口笛が入っていない切り出し） |

- step8 は「記憶を配列で思い出して吹く」とほぼ同じ成績。**つないだことで悪くはなっていない**。
- 規則の楽譜との差は、**記憶（step6）が楽譜を思い出す精度**から来ている。調のずれ（移調）と、1 音ずつ 20 cent ほどのずれ。
- 指揮役は、自分の選んだ状態を入力に戻して通しで動かしても 100 % 正しい。

## 記憶の改良（step6 の続き）

規則は口笛を「音域の両端（2 % と 98 % の音）のまん中」で笛の音域へ移す。平均しか持たない記憶では、これがわからず、曲ごとに平均 33 cent・ばらつき 60 cent 移調がずれていた。
記憶に、聞いている間の **なめらかな最高音・最低音**（`MemoryConfig.extremes`、2 つの足し算だけで、曲の長さによらず大きさ一定）を足した。

| 学習に使っていない実機の口笛 | mem_04 | mem_05（最高・最低音） | mem_06（＋書き込み 128 個・細かい損失） |
|---|---|---|---|
| 思い出した楽譜の誤差 | 65 cent | 33 cent | 31 cent |
| ±25 cent 以内 | 25 % | 50 % | 51 % |
| 鳴る・休むの一致 | 94 % | 92 % | 95 % |
| 思い出した楽譜で吹く（±25 cent、調を除く） | 未計測 | 25 %（41 %） | 36 %（47 %） |

合成の口笛では mem_06 が少し悪い所もあるが、実機の口笛を優先して mem_06 を使う。

2. **8b：全体の微調整**：耳・記憶・演奏・弁を PyTorch で 1 本につなぎ、1 話を丸ごと流して一緒に学習する。

## step8p — step7_practice をもとにした step8（2026-11-25）

step8 の 1 つの実行部（`Step8`）の演奏 NN・弁 NN を、実機で練習によって classic_ear を追い越した step7_practice のもの
（`nn_f80_t7_ilc_01`・`valve_t7_free`）に替えた。耳（ear_06）と記憶（mem_06）は step8 と同じ。`models/step8p/`。

- **練習**: 新しく聞き直さない限り、演奏 NN と「前の回の演奏の記録」を次の演奏に持ち越す（step7_practice が読む記録）
- **もう一度**: 切り替え役（`step8p_heads`）に「2 回押し（＝もう一度）」と「曲を覚えているか」の入力を足して学び直した
  （閉ループの正解率 100 %）。待機中の「もう一度」で、覚えている曲を練習として吹く
- **シミュレーター**（6 曲 × 4 台 × 3 回、72 話）: step7_practice が記憶から思い出した楽譜を練習を引き継いで吹く場合と同じ成績
  （1 回目 0.317 対 0.317、2 回目 0.358 対 0.348、3 回目 0.344 対 0.345）。72 話すべて自分で止まった（ずれ平均 0.01 秒）。
  模擬機体は毎回同じに外れるので、練習の上達はシミュレーターでは小さい（実機で確かめる）

### UNO Q で 10 ms に間に合わせる

| 処理 | 前 | 後 |
|---|---|---|
| 記憶への書き込み（1 歩） | 8.7 ms（129 × 8192 の行列に足す） | 値を並べるだけ（聞いている間の 1 歩は全部で平均 7.2 ms） |
| 記憶からの読み出し（1 時刻） | 6.1 ms | 吹く前のファンの準備中に、曲全体を FFT の畳み込みでまとめて読む |
| 演奏の 1 歩 | 平均 11.5 ms・最大 34 ms | 平均 7.4 ms・99 % で 8.1 ms |

W k_t = Σ_s v_s (k_s · k_t) で、k_s · k_t は時刻の差だけの関数 g(t − s) なので、読み出しは書いた値の列と g の畳み込みになる
（`MemoryRuntime.kernel` / `reads_from_kernel` / `decode_many`）。答えは W の形と同じ（PyTorch 版との差 0.002 cent 以内）。
PC の学習と ONNX は W の形のまま。

### 実機での動かし方

演奏サーバーが step8p をループの中で 10 ms ごとに回す（`step8_start` / `step8_finish` / `step8_stop` / `step8_status`）。
画面の「録音」で聞き始め、「録音終了して演奏」で吹いて、終わると自分で止まる。「練習：もう一度」で練習。
**基板の EXEC ボタンは、いつ押しても「すべて止めてリセット」**（2026-11-25 から。録音・演奏の開始は Web と Tab5 の画面だけ）。

まだ: 実機で人が口笛を吹いての評価（練習で上達するか）、ONNX 1 本への書き出しを練習の記録込みに直すこと。

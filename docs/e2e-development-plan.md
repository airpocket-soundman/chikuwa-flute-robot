# E2EフィジカルAI 開発計画

2026-09-22改訂。最終的な推論は生のお手本音声と生の自己音からPWM・バルブを出す1モデルとする。ただし、総合音程誤差だけで学習を進めず、内部機能を分けて学習・評価し、前段の合格後にだけ次段へ接続する。

## 基本原則

- 推論時にYIN、外部音程列、物理式、手書きPIDを入れない
- 訓練時の音程・位置・rigパラメーターは、報酬と補助教師に限って使用できる
- 各段階に単体評価、分布外評価、アブレーションを置く
- 一定音、2音ステップ、グリッサンド、短い旋律、一般曲の順に難しくする
- 合格していない機能を強化学習で隠さない
- 最終的に全モジュールを結合し、低学習率でE2E微調整する

## 構造

```text
お手本raw音声 → 共有ニューラル聴覚 → 参照系列メモリ → 時刻tの目標潜在表現 ─┐
                                                                            ├→ 誤差比較器
自己音raw音声 → 共有ニューラル聴覚 → 因果的自己音表現 → 遅延整合 ──────────┘
                                                                                 ↓
                                                        rig適応記憶 → FF＋FB制御器
                                                                                 ↓
                                                                         PWM・バルブ
```

制御出力は内部的に `feedforward plan + feedback residual` とする。中間表現はニューラル潜在量でよく、推論時に人手で計算した音程へ変換しない。評価用デコーダーは残し、内部機能が退化していないことを継続監視する。

## 開発ゲート

| Gate | 問い | 独立試験 | 仮合格基準 |
|---|---|---|---|
| 0 可制御性 | 機体が物理的に曲を演奏できるか | Oracle、速度・音域・発音遅延 | Oracle MAE 50 cents未満、到達不能率1%未満 |
| 1 聴覚 | raw音声から音高と発音を取れるか | 未知音色・雑音・マイク条件 | 音高MAE 50 cents未満、発音F1 0.95以上 |
| 2 記憶 | 録音後もお手本軌跡を保持できるか | 参照メモリだけから全軌跡を復元 | MAE 60 cents未満、変化方向90%以上 |
| 3 FF再現 | 自己音なしで旋律変化を駆動できるか | 名目rig、一定音→2音→glissando | 軌跡相関0.9以上、変化方向95%以上 |
| 4 差判定 | 目標と自己音の差が分かるか | ±50/100/300 centsを注入 | 符号90%以上、誤差MAE 60 cents未満 |
| 5 FB修正 | 差を正しい方向へ減らせるか | 外乱ステップ応答 | 初動方向98%以上、200 ms後に誤差50%以上減少 |
| 6 反復適応 | 同じ身体で吹くほど改善するか | 記憶保持/消去、rig交換 | 3回目が1回目より有意に良い |
| 7 sim-to-real | 実機にも移るか | 実機ログの時系列ホールドアウト | fit外誤差が事前基準より改善し、合成のみとの差を報告 |

基準値は最初の仮値であり、実機のOracle限界と測定雑音を得た後に更新する。

## 評価で必ず分ける量

- 音程MAEだけでなく、軌跡相関、上昇下降方向、変化開始時刻、定常誤差
- 発音率、音符開始・終了、休符漏れ
- 誤差推定の符号、量、遅延
- 閉ループの整定時間、オーバーシュート、発振
- 記憶保持と記憶消去の差、rig交換後の回復
- クリーン、音響乱数化、実録音ホールドアウト

## 学習順序

1. 共有ニューラル聴覚を音高・発音補助教師で学習
2. 凍結した聴覚の上で参照メモリ復元プローブを学習
3. 既知の音程差を注入し、差判定プローブを学習
4. プローブが合格した表現だけをFF制御器へ接続
5. FFが単純課題を通過後、FB残差制御器を接続
6. ステップ応答が安定後、演奏間rig適応を学習
7. 全体を結合し、各補助損失を残したままE2E微調整
8. 実機ログでシミュレーターを校正し、再学習・再評価

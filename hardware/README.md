# やまびこ1号の基板（KiCad 10）

| フォルダ | 中身 |
|---|---|
| `yamabiko_a/` | **A 基板**: UNO Q の R3 ヘッダーに挿す Arduino シールド（外形は Arduino Uno、ねじ穴なし）。リニアアクチュエーター（TB6643KQ）、ファン（ハイサイドスイッチ、PWM、タコ）、SCS0009（6 V レギュレーター、半二重バッファ）、控えの電磁弁、演奏開始ボタン |
| `yamabiko_b/` | **B 基板**: UNO Breakout Carrier の J14 / J15 に載せるマイク基板。ICS-43434 を MCU の SAI1（3.3 V）へ、予備で MI2S0（1.8 V）へ。**J14 の左には何も出さない**（UNO Q が載る）: 基板の左端は J14 のすぐ外で切り、部品は J15 の右に並べて、Carrier の右端から 13 mm はみ出す。マイクの L/R は GND 固定（左スロット）。予備に I2C（J15-16 / 18 = PF14 / PF15、4.7 kΩ プルアップ）と ADC / GPIO（PA0 / PA1 / PA3）を XH で出す |
| `lib/` | プロジェクトのシンボルとフットプリント（TB6643KQ、ピン番号 1 = G / 2 = D / 3 = S の FET） |
| `gen/` | 上の 2 つを作るスクリプト |

部品はすべて秋月電子通商のスルーホール品、コネクターは XH。部品表と IO 仕様は公開ページにまとめてある
（部品表: <https://claude.ai/artifact/Dvwt1oD2amMsziMAJQZxBU>、IO 仕様: <https://claude.ai/artifact/3YuJc5qp5sogrEiBCrkaD5>）。

## 作り方

回路図と基板は手で描いていない。**`gen/design.py` の部品・ネット・配置が正**で、そこから生成する。

```
gen/build.sh FREEROUTING.jar REPORT_DIR
```

1. `gen_boards.py`（KiCad の Python）: `design.py` から回路図を書き、KiCad にネットリストを出させて `design.py` と照合してから、
   同じネットで基板を作る。A 基板の外形と R3 ヘッダーの位置は KiCad の `Arduino_Uno` テンプレートのもの
2. `route.py`: Specctra DSN を書き出して [Freerouting](https://github.com/freerouting/freerouting)（v2.4.1 を使用。リポジトリには入れていない）で自動配線し、
   結果を取り込んで両面に GND ベタを張る
3. `finish_route.py`: Freerouting が残した接続があれば、2 層の格子上の A* で引く
4. `check.sh`: ERC、DRC（回路図との一致を含む）、配置図

シルクには全部品の部品番号と、抵抗・コンデンサの値を入れる（電解コンデンサは容量だけ。耐圧は部品表）。XH コネクターと SW1 は部品番号に接続先の名前を添え（例: `J3 FAN`）、コネクターは各パッドの脇にピン名を入れる（`design.py` の `device` / `pin_names`）。UNO Q のヘッダー J101〜J104 の番号はシルクに出さない。文字の位置は `gen_boards.py` が部品ごとに上下左右などの候補から、パッド・シルクの図形・ほかの文字・基板の端と重ならないところを選ぶ。

生成した時点の結果（2026-09-18）: 両基板とも ERC 0、DRC のエラー 0、未接続 0、回路図との不一致 0。
警告は A 基板で、シルクが基板の端に近い 2 件と、R8 / R9 の値がヘッダー J101 の枠線にかかる 2 件、GND ベタのサーマルの本数。

KiCad の Python（pcbnew）には落とし穴がある: 読み込んだ基板から `Remove` すると、そのプロセスではそれ以降の SWIG の
ラッパーが壊れる（`SwigPyObject` が返る）。スクリプトはすべて、削除を pcbnew ではなくファイル側で行う。
また、基板を保存すると `.kicad_pro` が既定のネットクラスで上書きされるので、プロジェクトファイルは基板の後に書く。

## 組み立ての注意

- **A 基板の R3 ヘッダー**: 3D 表示では上向きに立っているが、実物はオスのピンヘッダーを上から挿してピンを下に出し、UNO Q のソケットに挿す
- **B 基板の J14 / J15**: 3D 表示ではオスヘッダーだが、実物は **2×20 のメスのピンソケットを裏（下面）に付けて** Carrier の J14 / J15 にかぶせる。
  パッドの並びは Carrier の上面図と同じ（上から見て奇数ピンが左列、1 番ピンが上端）
- **B 基板の J2 は 1.8 V**（MI2S0）。3.3 V の線をつながない
- **B 基板の予備 I2C（J3）** は PF14 / PF15。UNO Q の Arduino コアの既定の I2C4 は PD12 / PD13 なので、使うときはピンの割り当てを切り替える
- **TB6643KQ の裏の金属部分**は IC の GND（4 番ピン）とつながっている。4 番ピンは検出抵抗 R1 を通って GND に落ちるので、放熱器を付けるなら絶縁する
- **2N7000（Q2, Q3）** は足を 2.54 mm に広げて挿す（フットプリントが `TO-92_Inline_Wide`）
- 控えの電磁弁まわり（Q4, R15, R16, D1, J5）は DNP。必要になったら実装する
